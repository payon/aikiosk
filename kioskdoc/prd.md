# 제품 요구사항 명세서 (PRD)

## 1. 프로젝트 개요
- **프로젝트명**: 시니어 맞춤형 멀티테넌트 키오스크 교육 플랫폼 (가제: KioskEdu CMS)
- **목적**: 하드코딩 없이 드래그앤드롭(DnD)으로 템플릿을 조립하여 15/21/32인치 키오스크에 배포할 수 있는, Xibo 형태의 멀티테넌트 관리 시스템 구축.
- **목표 사용자**: 
  - 수퍼 관리자: 전체 센터/지역 통합 관리, 권한 승인, 템플릿 마스터 관리.
  - 서브 관리자(센터장): 서브도메인 기반 로그인, 자체 키오스크 템플릿 커스터마이징 및 배포.
  - 최종 사용자(시니어): 고대비, 큰 버튼, 음성 안내, 물리 버튼 지원이 적용된 키오스크 화면 이용.

## 2. 핵심 기능 요구사항
1. **멀티테넌시 아키텍처**: 서브도메인(`centerA.kioskedu.com`) 기반의 데이터 격리 및 RBAC(Role-Based Access Control).
2. **비스포크 템플릿 엔진**: JSON 기반의 드래그앤드롭 에디터. 이미지, 텍스트, 버튼, 데이터 바인딩(DB/JSON)을 시각적으로 배치 및 수정 가능.
3. **멀티 디바이스 대응**: 15인치, 21인치, 32인치 해상도에 자동 적응하는 반응형/적응형 레이아웃 엔진.
4. **클라이언트 배포**: Windows/Linux용 Tauri 2 앱, Android용 PWA/TWA(Trusted Web Activity).
5. **하드웨어 시뮬레이션 및 연동**: Bixolon 영수증 프린터 드라이버 연동, Posbank 카드 결제 인식 시뮬레이션(교육용 출력 트리거).
6. **시니어 접근성**: WCAG 2.1 AAA 준수, 고대비 모드, TTS(음성 읽기), 물리 키보드 단축키 매핑, 이어폰 잭 감지.

## 3. 비기능 요구사항
- **성능**: 템플릿 로딩 시간 1초 이내, 키오스크 데모 모드에서 24시간 무정지 운영 안정성.
- **보안**: 하드웨어 UUID 기반 등록 승인, 모든 통신 TLS 1.3, 멀티테넌트 데이터 논리적/물리적 격리.
- **확장성**: 새로운 템플릿 컴포넌트(예: 퀴즈, 동영상 플레이어)를 플러그인 형태로 추가 가능한 구조.

# [프롬프트 목표] 제품의 비즈니스 목표, 기능/비기능 요구사항, 성공 지표를 정의한다.

## 1. 핵심 기능 요구사항 (Functional)
- **멀티테넌트 노코드 빌더**: 드래그앤드롭으로 15/24/32인치 키오스크 템플릿 및 페이지 플로우(시작→교육→설문→출력→홈) 생성.
- **동적 하드웨어 레지스트리**: 관리자가 UI에서 프린터/결제 시뮬레이션 드라이버를 추가/삭제/할당 가능.
- **설문 및 평가 엔진**: 교육 앱 수행 후 맞춤형 설문(객관식, 별점, 이모지) 표시 및 응답 수집.
- **통계 및 시각화 대시보드**: 센터별/기기별 '앱 수행 완료율', '설문 만족도', '중도 이탈률'을 차트(막대, 원, 라인)로 실시간 시각화.
- **하이브리드 배포**: 퍼블릭 클라우드 및 센터 로컬 폐쇄형 클라우드(On-Premise) 동시 지원.

## 2. 비기능 요구사항 (Non-Functional)
- **오프라인 퍼스트(Offline-First)**: 네트워크 단절 시에도 로컬 캐시된 템플릿으로 앱 수행 및 설문 응답이 가능해야 하며, 복원 시 자동 동기화(Sync)되어야 한다.
- **저사양 최적화**: 15인치 저사양 키오스크에서 무거운 차트 라이브러리가 실행되지 않도록, 시각화는 관리자 웹에 국한하고 키오스크는 경량 SVG 또는 텍스트 피드백만 사용한다.
- **보안 및 준수**: 설문 수집 시 개인정보(PII) 암호화 저장 및 K-PIPA(개인정보보호법) 준수 익명화 처리.

## 3. 성공 지표 (KPI)
- 템플릿 배포 후 키오스크 반영 시간 < 10초.
- 시니어 사용자의 설문 응답 완료율 85% 이상 (UX 개선 지표).
- 오프라인 환경에서의 데이터 유실률 0%.

- **핵심 기능**: 노코드 UI를 넘어, SQL/API 기반의 '데이터셋 레지스트리'와 '장바구니/세션 전역 상태 관리'를 지원하여 무인 카페, 도서관, 교통 등 복잡한 비즈니스 로직의 키오스크 앱을 100% 클론 가능해야 함.
- **액션 체인 빌더**: 버튼 클릭 시 다중 단계(API 호출 → 상태 업데이트 → 하드웨어 실행)의 로직을 시각적 노드로 연결하는 기능 필수.
