# 모바일/PWA/TWA UI/UX 가이드

## 1. TWA(Trusted Web Activity) 최적화
- Android Kiosk Mode 지원: 상단 상태바, 하단 네비게이션 바 숨김 (Immersive Mode).
- `manifest.json`: `display: "standalone"`, `orientation: "portrait"` (또는 landscape).

## 2. 모바일 특화 인터랙션
- 스와이프 제스처 방지 (시니어의 실수 방지).
- 물리 볼륨 버튼을 '다음/이전' 페이지 네비게이션으로 매핑 가능하도록 설정 옵션 제공.
- 이어폰 잭 삽입 감지 시: "이어폰이 연결되었습니다. 음성 안내가 이어폰으로 출력됩니다." 토스트 메시지 노출.

# [프롬프트 목표] 관리자가 이동 중에도 키오스크 상태와 통계를 모니터링할 수 있는 모바일 환경을 정의한다.

## 1. 모바일 최적화 대시보드
- **차트 단순화**: 복잡한 다중 축 차트 대신, 핵심 KPI(오늘 활성 기기 수, 평균 만족도, 오류 발생 건수)를 큰 숫자와 단순 도넛 차트로 표시.
- **실시간 알림**: 특정 키오스크에서 '용지 부족' 또는 '연속 오류 3회' 발생 시 푸시 알림(Push Notification) 또는 배지(Badge) 표시.
- **원격 제어**: 모바일에서 특정 기기 선택 → '화면 재시작', '캐시 초기화', '긴급 롤백' 버튼 제공.

- **실시간 트랜잭션 모니터링**: 특정 센터의 현재 '진행 중인 장바구니 수', '결제 실패율', '하드웨어 오류 코드'를 모바일 대시보드에서 실시간 스트림으로 확인 가능.
