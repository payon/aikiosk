# 키오스크 UI/UX 디자인 가이드 (15/21/32인치)

## 1. 시니어 친화적 디자인 원칙
- **터치 타겟**: 최소 48x48dp (실제 15인치 기준 약 1.5cm x 1.5cm 이상) 보장.
- **고대비 모드**: 기본 제공. 배경은 흰색/밝은 회색, 텍스트는 짙은 검정/남색 (#000000, #1A365D).
- **타이포그래피**: 가독성 높은 고딕 계열 (Pretendard, Noto Sans KR), 기본 폰트 크기 24px 이상.
- **피드백**: 버튼 클릭 시 명확한 시각적(색상 변경, 스케일 0.95) 및 청각적(경쾌한 클릭음) 피드백.

## 2. 드래그앤드롭 에디터 (Admin)
- **좌측**: 컴포넌트 팔레트 (텍스트, 이미지, 버튼, 동영상, 결제 시뮬레이션 블록).
- **중앙**: WYSIWYG 캔버스 (15/21/32인치 베젤 프리뷰 토글 지원).
- **우측**: 속성 패널 (선택한 컴포넌트의 텍스트, 이미지 URL, DB 바인딩 키, 고대비 설정).

## 3. 반응형 전략
- CSS Grid/Flexbox 기반. 15인치는 단일 컬럼 위주, 32인치는 2~3 컬럼 분할 레이아웃 자동 적응.

# [프롬프트 목표] 시니어 사용자를 위한 키오스크 화면 및 관리자 템플릿 에디터의 UX 원칙을 정의한다.

## 1. 시니어 키오스크 화면 원칙 (WCAG 2.1 AAA 준수)
- **터치 타겟**: 최소 64x64px (약 1.8cm).
- **설문 UI**: 텍스트 대신 '이모지(😊 😐 😞)' 또는 '큰 별점(⭐)' 활용. 음성 안내(TTS)가 질문을 읽어주고, 선택 시 "선택되었습니다" 음성 피드백 제공.
- **수행 능력 시각화(키오스크 측)**: 교육 완료 시 "수고하셨습니다! 오늘 학습 점수: 90점"과 같은 즉각적이고 긍정적인 시각/청각 보상 제공.

## 2. 관리자 템플릿 에디터 (No-Code Builder)
- **플로우 뷰**: 페이지 간 연결 선(Line)을 드래그하여 연결하는 노드 기반 에디터 제공.
- **설문 컴포넌트**: 팔레트에서 '설문 블록'을 드래그하면, 우측 패널에서 질문 유형(객관식, 이모지, NPS)과 데이터를 바인딩할 수 있는 UI 제공.
- **미리보기**: 15/24/32인치 베젤 프레임 내에서 실제 반응형 레이아웃을 시뮬레이션하는 토글 버튼 제공.

- **데이터 패널**: 좌측에 'UI 컴포넌트' 팔레트, 우측에 '데이터셋 및 액션' 패널을 배치.
- **시각적 바인딩**: '상품 리스트' 컴포넌트를 드래그한 후, 데이터 패널의 '커피 메뉴 데이터셋'을 드래그하여 컴포넌트에 드롭하면 자동으로 필드(이미지, 이름, 가격)가 매핑되는 UX 제공.
