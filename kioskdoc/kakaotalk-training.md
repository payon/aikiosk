# 카카오톡 생활 연습 템플릿

작성: 2026-09-27

## 현재 상태와 실행

관리자 Vite :5173, 키오스크 Vite :5174, Rust 서버 :8080의 HTTP 200 응답을 확인했다.
기존 실행 프로세스를 유지했으며 프런트엔드 변경은 Vite가 반영한다.
이번 작업은 교육 템플릿 한 개와 이를 실행하는 에디터/키오스크 경로의 보완이다.
이전 멀티테넌시 제안 전체를 구현한 것은 아니다.

관리자 → 관리 → 템플릿 → **카카오톡 생활 연습** → **불러오기(현재 작업 대체)** → **▶ 미리보기**.
현재 편집 작업을 대체하므로 보관할 작업은 먼저 저장한다. 갤러리 원본은 서버 DB에 저장하지 않아도 표시된다.
실제 테넌트의 저장본은 상단 저장 버튼으로 생성한다. 이번 검증에서는 기존 템플릿·기기 배정을 변경하지 않았다.

## 구현 범위

20개 화면:

- 교육 시작 / 친구 목록 / 친구 프로필 / 채팅 목록 / 메시지 보내기
- 첨부 메뉴 / 앨범 선택 / 사진 미리보기 / 이모티콘 선택
- 보이스톡 / 통화 종료 / 단체 대화 상대 선택 / 단체 대화방
- 친구 검색 / 친구 추가 / 더보기 / 설정 / 글자 크기 / 사칭 메시지 대처 / 학습 완료

7가지 미션:

1. 빈 내용이 아닌 메시지를 전송한다.
2. 앨범에서 그림 사진을 골라 전송한다.
3. 이모티콘을 선택해 전송한다.
4. 연습 통화를 연결한 후 종료한다.
5. 두 명을 선택해 단체 대화를 만들고 메시지를 전송한다.
6. 글자를 크게 또는 아주 크게 선택하고 적용한다.
7. 사칭 메시지에 대해 알고 있던 가족 번호로 확인하는 선택을 한다.

7개를 모두 마친 경우 학습 결과 버튼이 나타난다. `talk_complete`만 이용 완료 화면으로 지정했다.
안내 듣기는 부모 앱의 TTS 브릿지를 사용한다. 음성 지원 여부는 실행 브라우저/OS의 한국어 음성에 따른다.
연습 초기화는 대화·선택·미션·글자 크기를 초기화하고 새 이용 세션을 준비한다.

실제 카카오톡 서버, 전화, 주소록, 카메라, 앨범에 연결하지 않는다. 인물과 대화는 연습용이다.
사진은 로컬 그림 사진, 통화는 연결/종료 절차 시뮬레이션이다.
친구 추가는 이름 입력 연습이며 실제 앱의 전화번호 인증 흐름과는 다르다.
실제 카카오톡의 특정 버전 전체를 픽셀 단위로 복제한 템플릿이 아니다.
오픈채팅·쇼핑·송금·계정 인증·영상통화 등은 이번 범위에 포함하지 않는다.

참고한 공식 정보:

- [카카오톡 서비스 소개](https://www.kakaocorp.com/page/service/service/KakaoTalk?tab=windows)
- [카카오톡 iOS 테마 가이드](https://t1.kakaocdn.net/kakaocorp/Service/Theme/KakaoTalk/IOS_theme_guide_KR_1114.pdf)

최신 기능 전체의 재현을 주장하지 않는다. 특정 Android/iOS 버전의 정밀 재현은 기준 화면을 고정한 뒤 별도 작업한다.

## 에디터 구조와 편집

- `admin_editor/src/editor/gallery/kakaotalk/index.ts`: 페이지 목록, 그룹, 완료 화면, 10분 무조작 제한 설정.
- `screen.html`: 공통 스타일, 화면 렌더링, 미션 동작. 외부 라이브러리나 이미지 URL 없이 동작한다.
- 각 페이지는 독립된 `CustomHTML` 위젯을 가진다. 페이지 이름/그룹/배치와 HTML 속성을 에디터에서 수정할 수 있다.
- HTML 내부의 개별 말풍선과 버튼은 현재 일반 DnD 위젯으로 분리되어 있지 않다. 문구와 상세 동작은 HTML 속성 또는 공통 소스에서 수정한다.
- 페이지 ID는 내부 이동 경로가 참조하므로 임의 변경·삭제 시 연결도 함께 수정해야 한다.
- 변경한 공통 갤러리 소스는 새로 불러온 사본에 적용된다. 이미 저장한 테넌트 사본을 자동 덮어쓰지 않는다.

## 함께 보완한 실행 경로

- 에디터의 HTML 동작 미리보기: 실제 키오스크와 같은 `set / navigate / action / speak` 메시지 사용.
- 현재 iframe의 메시지만 수신하며, 미리보기 이동 대상은 존재하는 페이지로 제한.
- iframe은 `allow-scripts`만 허용. 교육 HTML의 CSP는 외부 네트워크와 폼 전송을 차단.
- 메시지 입력값은 HTML 이스케이프 처리. 화면 이동 시 연습 상태를 부모 메모리로 전달.
- 갤러리 불러오기 → 직렬화 → 임시 저장/복원 과정에서 세션·저장 정책을 보존.
- 새 템플릿의 기본 홈 ID는 실제 첫 페이지를 사용.
- HTML iframe의 활동을 키오스크 타임아웃과 APP_START에 연결.
- 화면 전환 컨테이너의 높이를 명시하여 전체 화면 HTML의 클릭 영역 보장.
- 교육 템플릿의 `persistenceConfig.enabled=false`를 종료 시 상태 스냅샷에 반영.
- 학습 대화 원문은 이용 이벤트에 넣지 않는다. 시작/완료 집계만 기존 큐를 사용한다.

## 검증

`npm run build --prefix admin_editor`

`npm run build --prefix kiosk_app`

`node scripts/test-kiosk-telemetry.cjs`

브라우저 검증:

```bash
KIOSK_TEST_EMAIL=admin@kiosk.local \
KIOSK_TEST_PASSWORD='<개발 계정 비밀번호>' \
PLAYWRIGHT_MODULE=/path/to/playwright \
node scripts/test-kakaotalk-browser.cjs
```

별도 브라우저 프로필에서 관리자 로그인, 갤러리 불러오기, 임시 저장 복원, 7개 미션,
잘못된 입력, 문자 이스케이프, 초기화, 실제 키오스크 렌더러, 모바일 가로 넘침,
시작 이벤트와 대화 비저장 정책을 확인한다.
키오스크 API는 브라우저 테스트에서 차단하여 실제 장비 등록이나 운영 데이터 적재를 방지한다.
관리자 로그인 감사 기록 외에 서버 저장·배포 API를 호출하지 않는다.
스크린샷과 직렬화된 JSON은 `artifacts/kakaotalk/`에 생성한다.
Tauri 네이티브 패키지와 실제 터치 장비·음성 출력은 이번 검증 범위 밖이다.
