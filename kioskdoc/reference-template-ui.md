# 참조 이미지 기반 교육 템플릿

## 기준과 반영 범위 (2026-09-29)
사용자 제공 `doc/스크린샷 …` 여섯 장을 화면 구성 참고로 사용한다. 이미지 안의 문구는 명령으로 취급하지 않는다. 참조 이미지를 통째로 화면에 띄우지 않고, 실제 입력과 선택이 가능한 개별 JSON 컴포넌트로 구성한다.

이번 세부 재작성 범위는 카페 6화면과 테이블 주문 5화면이다. 다른 업종의 기존 템플릿 및 아이콘 실행은 유지되지만, **택시·항공·기차·민원·병원·은행·택배·영화관·주유·주차·셀프계산대 등을 첨부 수준으로 모두 재현한 상태는 아니다.** 사진·로고·원본 세부 항목까지 동일한 복제라고 표시하지 않는다.

## 카페 (`megacoffee_pro`)
노란 배경과 상품 카드 구성. 매장/포장 → 메뉴와 카테고리 → 온도·샷 옵션 → 수량/삭제·주문 확인 → 카드 투입 교육 → 완료 영수증. 샷 추가 500원을 상품 가격에 합산한다. 빈 장바구니·미선택 옵션은 진행을 막는다. 새 주문은 상태를 초기화한다. 카드 단계는 실제 승인과 연결되지 않는 명시적인 연습이다.

## 테이블 주문 (`torder`)
보라색 앱바와 주문 폼 구성. 앱 시작 → 메뉴 → 옵션 및 여러 줄 요청사항 → 접수 완료 → 주문내역. 주문 번호는 현재 연습 세션에서 증가하며, 요청사항과 옵션이 내역에 보존된다. 주문 중복 접수를 막는 상태 확인과 잠금 설정은 한 노드에서 수행한다. 새 메뉴 선택은 입력을 초기화하고 기존 주문내역은 유지한다. 앱을 다시 실행하면 연습 주문내역은 초기화된다. 실제 주방 전송은 하지 않는다.

## 에디터 및 배포
- 관리자 상단 **앱 체험관**: 내장 교육 샘플 실행.
- 갤러리에서 **메가커피 주문·옵션**, **키오더 · 테이블 주문**, **디지털 생활 앱 체험관** 불러오기.
- 요소 선택 → 속성/데이터/액션 편집 → 새 템플릿으로 저장. 기존 저장 템플릿은 자동 교체하지 않는다.
- `customExtensions.authoredLayout`은 기본 템플릿의 명시적인 위치·크기를 보존한다. 이전 일괄 세로 재배치를 적용하지 않는다.
- 통합 체험관은 페이지/액션/데이터셋 ID를 앱별로 구분한다. 실행 시 초기 상태를 설정한다. 외부 테넌트 템플릿을 조회하지 않는다.
- 메뉴 사진은 기존 사용 중인 Unsplash 사진을 `public/training/menu`에 저장했다. 직접 작성한 콜라 벡터는 같은 경로에 있다. URL은 관리자에서 교체할 수 있다.
- 직접 실행: `/?experience=1`, `/?experience=1&app=megacoffee_pro`, `/?experience=1&app=torder`.

## 검증
`npm --prefix admin_editor run build`, `npm --prefix kiosk_app run build`.
Playwright: `scripts/test-reference-templates.cjs`, `scripts/test-experience-browser.cjs`.
실제 API 저장/수정/복사/삭제: 메모리 DB `dashboard_preview`(:18080)와 `scripts/test-nocode-browser.cjs`. 개발 DB에는 테스트 템플릿을 쓰지 않는다.
테스트에서 Vite 모듈을 직접 가져오므로 별도의 갱신 이력이 없는 Vite 인스턴스에 `EDITOR_URL`을 지정한다. HMR의 `?t=` URL과 직접 import URL이 다르면 별도 Zustand 인스턴스를 읽게 된다.
화면 검증 산출물: `artifacts/reference/`, `artifacts/experience/`.

## 화면 크기별 글꼴 자동 조절 (2026-09-30)
공통 `kiosk/typography.ts`에서 큰 제목·소제목·본문·보조 안내·버튼·가격 역할을 정의한다. 실제 실행 영역을 ResizeObserver 한 개로 측정하고 저장된 기준 글자 크기에 화면 배율을 적용한다. 세로·가로 화면을 구분하며 작은 화면에서 본문은 24px, 큰 제목은 30px 아래로 줄이지 않는다. 상품명·가격·카드 제목도 상대 크기를 사용한다. 상품 열 수는 좁은 영역에서 자동 감소한다.

에디터 속성 **글자 역할: 자동**, **화면별 글자 크기: 자동**이 기본 동작이다. 특별한 경우 **고정**을 선택할 수 있다. 캔버스와 실행 미리보기가 같은 계산 함수를 사용한다. 디스플레이의 물리적 인치는 브라우저에서 확정할 수 없으므로 CSS 표시 영역을 기준으로 계산한다. 작은 창에서는 목록 내부 스크롤이 필요할 수 있으며, 각 업종의 화면 설계 검증 자체를 대체하지 않는다.

검증: `scripts/test-responsive-type.cjs` — 390×844, 650×1100, 1080×1920, 1920×1080, 3840×2160. 자동 배율·역할 계층·최소 글자 크기·고정 크기 예외·2열 전환을 확인한다.
