# [프롬프트 목표] 외부 의존성(하드웨어, 네트워크)을 격리하여 테스트할 수 있는 목(Mock) 환경을 정의한다.

## 1. 하드웨어 목 서버 (Mock Hardware Server)
- 로컬 포트 9100에서 리스닝하는 가짜 프린터/카드 리더 서버.
- 특정 JSON 명령을 받으면 `{"status": "success", "simulated": true}`를 반환하고, 확률적으로 `{"status": "error", "code": "PAPER_JAM"}`을 반환하여 오류 처리 로직을 테스트할 수 있게 함.

## 2. 네트워크 장애 주입 (Chaos Engineering Lite)
- Tauri 클라이언트 테스트 시, `reqwest` 요청에 인위적인 지연(Delay) 또는 실패(Failure)를 주입하여 오프라인 큐잉 및 재시도(Retry) 로직이 정상 작동하는지 검증하는 하니스 제공.

- **도메인 시뮬레이터**: 커피, 도서관, 교통 등 각 도메인별 더미 데이터셋과 API 응답을 생성하는 목(Mock) 서버를 제공하여, 실제 외부 API 없이도 키오스크 플로우를 완벽히 테스트할 수 있는 환경 구축.
