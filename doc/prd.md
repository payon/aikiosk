2. prd.md (제품 요구사항 문서)
2.1. 제품 비전
개발자와 비개발자 모두가 디지털 에셋과 AI/헬스케어 솔루션을 단일 플랫폼에서 직관적으로 탐색하고 이용할 수 있는, 스타일리시하고 확장 가능한 통합 솔루션 허브를 제공합니다.
2.2. 핵심 기능 요구사항 (Functional Requirements)
통합 앱 런처 (App Launcher)
사용자가 로그인 시, 권한이 있는 앱들을 아이콘 그리드로 표시.
그리드는 화면 크기에 따라 2열(모바일), 3열(태블릿), 4열(데스크탑/키오스크)로 자동 조정.
각 아이콘 카드는 4:5 종횡비를 유지하여 시각적 일관성과 피드 최적화 확보.
동적 앱 관리 (Admin Dashboard)
관리자가 앱 이름, 슬러그, 타겟 URL, 아이콘, 설명, 활성 상태를 등록/수정/삭제.
저장 즉시 캐시가 무효화되고, 전체 사용자의 런처에 실시간 반영.
공유 셸 레이아웃 (Unified Shell)
앱 실행 시 상단 글로벌 헤더(유저 프로필, 알림)와 좌측 사이드바(앱 전환 메뉴)가 유지됨.
모바일에서는 사이드바가 하단 내비게이션 바(Bottom Nav) 또는 햄버거 드로어로 전환.
무결점 SSO (Single Sign-On)
코어 플랫폼 로그인 세션을 서브 앱이 신뢰하여 추가 로그인 없이 바로 서비스 이용 가능.
2.3. 비기능 요구사항 (Non-Functional Requirements)
반응형 지원: 320px(모바일) ~ 2160px(4K 키오스크 세로형)까지 완벽 대응.
성능: LCP(Largest Contentful Paint) 1.5초 이내, 미들웨어 지연 시간 10ms 미만.
접근성: WCAG 2.1 AA 기준 준수 (명도 대비, 키보드 포커스, 스크린 리더 지원).
